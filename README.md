# For My Princess Ishuu 👑
React + Vite + Framer Motion surprise site. Characters are original SVG illustrations (no copyrighted art); music is synthesized in-browser (no audio files needed); fonts are bundled via @fontsource.

## Run locally
1. Install Node 18+ 2. `npm install` 3. `npm run dev` and open the URL shown.

## Publish (GitHub Pages)
1. Create an empty repo on github.com (e.g. `princess-ishuu`).
2. `git init && git add . && git commit -m "For Ishuu" && git branch -M main`
3. `git remote add origin https://github.com/YOUR-USERNAME/princess-ishuu.git && git push -u origin main`
4. Repo → Settings → Pages → Source: **GitHub Actions**.
5. Wait for the Actions run to finish, then open `https://YOUR-USERNAME.github.io/princess-ishuu/`
